# Client Info — Información cruda del cliente

> **Qué es este archivo:** el vertedero. Pega aquí TODO lo que el cliente te entrega,
> tal cual, sin ordenar ni formatear. Es la materia prima.
>
> **Qué NO es:** no es el documento de requisitos. La IA transforma esto en
> `requirements.md` (estructurado) mediante el prompt `01-analyze-requirements.md`,
> y tú lo validas. No edites este archivo para "mejorarlo": mientras más fiel al original,
> mejor detecta la IA huecos y contradicciones.
>
> *(Solo se usa en el perfil `full`. En `standard` escribes `requirements.md` directo.)*

---

## Cómo usar

1. Pega todo abajo: notas de reunión, mensajes, correos, audios transcritos, documentos,
   capturas descritas, ideas sueltas del cliente.
2. No borres contradicciones ni cosas incompletas: son señales que la IA debe detectar.
3. Marca la fuente de cada bloque si la recuerdas (útil para la trazabilidad en `requirements.md`).
4. Cuando termines, ejecuta el prompt 01 para generar `requirements.md`.
